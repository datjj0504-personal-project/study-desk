# Folder Structure

| Path | Purpose |
| --- | --- |
| `main.go`, `app.go` | Wails entry point and bound adapter (generated by `wails init`, then edited). |
| `wails.json`, `package.json` | Wails and tooling configuration (generated). |
| `build/` | Wails build assets; `build/bin/` holds outputs (ignored). |
| `build-tools/` | Helper scripts for dev/release. |
| `cmd/` | Auxiliary Go executables, if ever needed. |
| `internal/notes` | Notes domain logic. |
| `internal/timer` | Pomodoro and stopwatch logic. |
| `internal/study` | Study sessions and statistics. |
| `internal/storage` | SQLite access and repositories. |
| `internal/settings` | User settings. |
| `migrations/` | Versioned SQL migrations. |
| `frontend/src/` | React app: `components`, `pages`, `hooks`, `services`, `types`, `utils`. |
| `frontend/wailsjs/` | Generated bindings (ignored; never edit). |
| `tests/` | Cross-package integration tests. |
| `docs/` | Project documentation, numbered by phase. |
| `ai/` | Persistent context and prompts for AI coding agents; see [ai/README.md](../../ai/README.md). |

Directories that contain only a README are reserved; Go packages are added when implemented. See [architecture](architecture.md).
