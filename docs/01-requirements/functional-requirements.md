# Functional Requirements

Initial draft. IDs are stable references for tasks and tests.

## Notes

- FR-N1: Create, edit, and delete notes with a title and body.
- FR-N2: List notes sorted by last update.
- FR-N3: Search notes by title and body text.
- FR-N4: Optionally tag a note with a subject.

## Timer (Pomodoro)

- FR-T1: Start, pause, resume, and reset a focus timer.
- FR-T2: Alternate focus, short break, and long break phases.
- FR-T3: Configurable durations (default 25/5/15 minutes).
- FR-T4: Notify the user when a phase ends.

## Stopwatch

- FR-S1: Start, pause, resume, and reset a stopwatch.
- FR-S2: Display elapsed time with second precision.

## Study Sessions

- FR-SS1: Record a session (start, end, duration, optional subject, optional note) when a focus timer or stopwatch completes.
- FR-SS2: Add, edit, and delete sessions manually.
- FR-SS3: List past sessions by date.

## Statistics

- FR-ST1: Show total study time for today, this week, and all time.
- FR-ST2: Show time per subject.
- FR-ST3: Show daily totals for the last 7 and 30 days.

## Settings

- FR-SE1: Persist timer durations and preferences locally.
