# pages/

Top-level screens (Notes, Timer, Stopwatch, Settings, Sessions, Statistics) composed from components, hooks and services. `NotesPage` supports title/body search, subject filtering and assignment, subject creation, note create/edit/delete, and debounced autosave. `TimerPage` presents Pomodoro or stopwatch controls and polls backend snapshots for elapsed/remaining-time updates. `SettingsPage` configures persisted Pomodoro durations and system notifications.
